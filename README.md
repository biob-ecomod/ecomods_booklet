Welcome! 

This repository uses [Bookdown](https://bookdown.org/yihui/bookdown/) to create the GitHub page: 
https://biob-ecomod.github.io/ecomod_booklet/

The rendered book is a collection of guides and tips to help members of the  
Ecological Modelling (Ecomod, a.k.a. AG Sarmento Cabral) research group at the 
Bonner Institut für organismische Biologie (BIOB) navigating ecological 
modelling and working at the Ecomod lab in general.

This book is an update of the one maintained by the former EcoMods group at the
University of Würzburg.
