Chapter 1 About this book

Hello and welcome to the EcoMods working group!

In this document, you will (hopefully) find everything you need for your course / internship / thesis with us.

The book is meant to be a live document, and will be updated continuously. As you browse through sections, you will encounter empty or incomplete sections. You’re welcome to ask for sections to be added, updated, or even better, improve it yourself! See section ??.

1.2 Contributing to this book

We gladly accept any suggestions on how to improve this guide, so let us know if you feel that anything is missing!

This booklet is a bookdown document. This means, that it consists of several R Markdown files. To learn R markdown see section 2.1.1.4. The booklet is hosted on GitHub (see section 2.1.3.

  1. Step: Clone the repository from GitHub.

  2. Step: Open the .rmd file of the Chapter you would like to change.

  3. Step: Do your changes.

  4. Step: Commit your changes and push them on GitHub.

  5. Step: Then the magic happens: via github actions the website will be updated, but this takes 5-10 Minutes (check the green dot!). This creates files that are pushed automatically. Therefore, don’t work within the Repo while waiting and pull the changes before you go on editing.

Don’t forget to add links, citations, figures etc in a nice and organized way. Check text for typos and readability and be sure that a beginner can understand it.

1.5 Induction

Welcome to the group! We hope you have a great time with us and that your experience in your lab will be the opportunity to develop your academic skills and explore exciting research!

Here are some things you should consider upon joining us:

  • 🔑 Keys: our lab is hosted in the old NEES institute, Venusbergweg 22, at the edge of the Botanische Gärten. Access to the building and other facilities of the institute is managed through transponders, which you must obtain in person from Elke Friesecke at the main building of the Nees-Institut (Meckenheimer Allee 170). You will need to return the transponders upon leaving.

  • 🔘 Slack: we have a Slack workspace for the group, which is our main channel for communication. You will find links to the lab meeting schedule and zoom call pinned in the #general channel. Ask another team member for an invite link!

  • 🗨️ Whatsapp: we have a Whatsapp convo for instant communication (mostly socials). Ask a team member for an invite if you’d like to join.

  • 📆 Calendar: We keep a Google Calendar to pin and share relevant events. If you’d like to get access, send a google account address to Theo.

  • 👥 Meetings: save these time slots for regular meetings:

    • Weekly Ecomod lab meeting, Mondays 17:00-18:00.
    • NEES seminar (jointly with Prof. Max Weigend’s group) Tuesdays 16:30-17:30

The schedule for the lab meetings is available here. It is also possible to join online, the zoom link is pinned in the Slack’s general channel.

  • 🤖 IT questions: Theo can help with all research-related software enquiries. For hardware issues, the responsible person for BIOB is Tomislav Balen. In particular, for security reasons our printer can only be accessed with specific drivers, which are to be installed by Tomi.

  • 📖 University Library: before using the services of the ULB (Universitäts und Landesbibliothek Bonn), you will need to get yourself a library ID card (Bibliothekausweis) and a user account, which are not automatically created upon joining the University. The procedure is detailed on the ULB website. You will need to submit a form, get the Uni Bonn app and after a few days you will receive instructions on how to link your Uni-ID into the app. Finally, you will need to head to the main ULB building to show a piece of ID, proof of residence and proof of affiliation with Uni Bonn (enrolment certificate or work contract).
